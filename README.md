# 魚仕分け

そっくりな2匹の魚のイラストから、正しい方を選ぶ2択クイズゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要・外部ライブラリなし）。

- 「はじめる」で10問出題。「○○はどっち？」の問いに、左右どちらかのイラストをタップ
- 回答後に **見分けポイント** を表示
- 結果画面では、まちがえた魚をおさらい
- 「見分け図鑑」で全ペアの特徴を確認
- キーボード：`←` / `1` で左、`→` / `2` で右

## 収録ペア（12組）

| ペア | 見分けポイント |
| --- | --- |
| アナゴ / ウナギ | 白い点々（側線孔）、あごの出かた |
| ヒラメ / カレイ | 左ヒラメに右カレイ、口の大きさ |
| マグロ / カツオ | お腹の縞、黄色い小離鰭 |
| アジ / サバ | ぜいご・エラの黒点 / 背中の波模様 |
| サンマ / サヨリ | 針のように長い下あご（先が赤い） |
| マダイ / クロダイ | 青い斑点・尾びれの黒いふち |
| ブリ / カンパチ | 目を横切る「八」の字の帯 |
| フグ / カワハギ | 白縁の黒い紋 / 頭のトゲ |
| コイ / フナ | ひげの有無 |
| サケ / ニジマス | ピンクの帯と黒い斑点 |
| マイワシ / カタクチイワシ | 七つ星 / 突き出た上あご |
| サメ / イルカ | エラ穴・尾びれの向き（イルカはほ乳類） |

## ファイル構成

- `index.html` … 画面
- `css/style.css` … スタイル
- `js/fish.js` … 魚のイラスト（SVG をコードで生成）
- `js/data.js` … 出題ペアと見分けポイント
- `js/game.js` … ゲーム進行

## 問題の追加方法

1. `js/fish.js` の `art` に新しい魚の描画関数を追加（`spindle()` を使うと紡錘形の魚を簡単に描けます）
2. `js/data.js` の `FISH_PAIRS` にペアと見分けポイントを追加
