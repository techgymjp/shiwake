# 魚仕分け

寿司屋の大将の「マグロを一丁たのむ！」という注文にこたえて、そっくりな2匹の魚のイラストから正しい方を選ぶ2択クイズゲームです。

## 遊び方

▶ **https://techgymjp.github.io/shiwake/** で遊べます。


`index.html` をブラウザで開くだけで遊べます（ビルド不要・外部ライブラリなし）。

- 「板場に立つ！」で10問出題。大将の注文を聞いて、左右どちらかのイラストをタップ
- 回答後に **見分けポイント** を表示
- 結果画面では、まちがえた魚をおさらい
- 「見分け図鑑」で全ペアの特徴を確認
- BGM・効果音・大将の声（音声読み上げ）は右上のボタンで ON/OFF
- キーボード：`←` / `1` で左、`→` / `2` で右

## 収録ペア（50組・83種）

1回のプレイで、50組の中からランダムに10問出題します。全ペアと見分けポイントはゲーム内の「見分け図鑑」で見られます。

- **寿司ネタ・市場の魚**：マグロ / カツオ / キハダ / カジキ、ブリ / ヒラマサ / カンパチ、アジ / シマアジ / ムロアジ、サバ / ゴマサバ、マダイ / チダイ / クロダイ、キンメダイ / キンキ、ヒラメ / カレイ / シタビラメ、イワシ / カタクチイワシ / ニシン、サンマ / サヨリ、カマス / サワラ、ホッケ / シマホッケ、マダラ / スケトウダラ など
- **磯・沿岸の魚**：イシダイ / イシガキダイ、メバル / カサゴ、スズキ / ボラ、キス / ハゼ、ホウボウ / カナガシラ / トビウオ、フグ / ハリセンボン、カワハギ / ウマヅラハギ、アンコウ / オコゼ、タチウオ / ハモ、ウナギ / アナゴ / ウツボ、サメ / イルカ / エイ
- **川・池の魚**：コイ / フナ / キンギョ、ナマズ / ドジョウ、メダカ / カダヤシ、アユ / ワカサギ、ヤマメ / アマゴ / イワナ、サケ / ニジマス、ブラックバス / ブルーギル
- **魚介**：イカ / タコ、クルマエビ / シャコ、ホタテ / カキ、ハマグリ / アサリ、サザエ / アワビ

## ファイル構成

- `index.html` … 画面
- `css/style.css` … スタイル
- `js/fish.js` … 魚のイラスト（SVG をコードで生成）
- `js/data.js` … 出題ペアと見分けポイント
- `js/sound.js` … 効果音・BGM（Web Audio で合成）と大将の声（音声合成）
- `js/game.js` … ゲーム進行・大将のセリフ

## 問題の追加方法

1. `js/fish.js` の `art` に新しい魚の描画関数を追加（`spindle()` を使うと紡錘形の魚を簡単に描けます）
2. `js/data.js` の `FISH_PAIRS` にペアと見分けポイントを追加

## 公開（GitHub Pages）

`.github/workflows/pages.yml` が push のたびにサイトをデプロイします。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
