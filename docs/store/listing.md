## 日本語

**アプリ名**（30 文字以内）

```
魚仕分け - そっくりな魚を見分けるクイズ
```

**簡単な説明**（80 文字以内）

```
寿司屋の大将の注文にこたえて、そっくりな2匹から正しい魚を選べ！ヒラメとカレイ、アナゴとウナギ…全100組の見分けクイズ。
```

**詳しい説明**

```
「へいっ！ヒラメを一丁たのむ！」
寿司屋の大将の注文にこたえて、そっくりな2匹の魚から正しい方を選ぶ2択クイズです。
ヒラメとカレイ、アナゴとウナギ、マグロとカツオ、ブリとカンパチ…。
特徴をおさえたイラストを見比べて、あなたの「目利き」の腕前をためしてみましょう。

■ そっくりな魚が全100組・145種類
・寿司ネタ・市場の魚、磯・沿岸の魚、川・池の魚、イカ・エビ・貝の4ジャンル
・ジャンルを選んで遊べる（ぜんぶ混ぜて遊ぶこともできる）
・1回10問。「やさしい」から「むずかしい」の順に出題

■ 答えるたびに「見分けポイント」
・正解・不正解のあとに、2匹の見分け方をひとことで解説
・「左ヒラメに右カレイ」「マダイは尾びれのふちが黒い」など、魚屋さんや釣りで役立つ知識が身につく
・「見分け図鑑」で、全100組の見分けポイントをいつでも確認できる

■ 寿司屋の大将といっしょに
・大将が注文し、正解するとほめ、まちがえると「そいつはカツオだ！」とツッコミ
・連続正解でどんどん盛り上がる
・成績に応じて「皿洗いから修行」から「大将も認める目利き」までの称号

■ ランキングとシェア
・正解数とタイムで、ジャンルごとのランキング（この端末に保存）
・結果を⭕❌の並びといっしょに友だちにシェア
・まちがえた問題は、広告を見て別の問題でやり直せる（1回のプレイで3回まで）

■ その他
・ポップなデザインと、効果音・BGM
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

さあ、板場に立って、目利きの腕前を見せてくれ！
```
